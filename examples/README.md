# 黄金样例（不是模板）

两份**填满**的 change，演示四要素如何回答四个问题。照抄**结构**，不要照抄数字与结论。

- `doc-change/`：文档类。check 以命令 + 结构断言为主，标了独立验收人；tasks 含决策权/启停条件。
- `experiment-change/`：实验类。P0 基线 + 相对目标 + A→B→A' 交错 + 数据落 `data/` + 包络裁决。

两份都刻意展示了容易漏的字段：

- spec 的基线写 `待测（tasks P0）`、目标写相对式、测量口径写全；
- design 的决策理由、观测点、`待勘察（P0）` 标记；
- tasks 的接手须知（含决策权/启动/停止）、每条任务的判据、变更记录、结果表；
- check 的「阈值引 spec」「验收人」。
