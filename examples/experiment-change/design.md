# rx-ring-ab — 设计

## 事实约束

| 约束 | 说明 |
|------|------|
| 驱动版本 | 与仓库基线一致，除目标变量外零漂移 |
| ring 范围 | 128–1024，需为 2 的幂 |
| 测试环境 | 独立 AP，固定信道 |

## 现状路径

RX ring 256；高负载下 ring 满，drop 上升，重传增加。

## 目标路径

ring 512；只改一个常量，其余路径不变。

## 核心设计

- 只改 ring，不动 NAPI 与聚合：变量隔离。
- 用 A→B→A' 而非单次 A/B：环境时段漂移可能大于版本差。
- 双结局预写：B 超 A/A' 包络才合入；否则记录证据并回退。

## 资源预算

- 内存 +约 512KB；代码 1 行。

## 风险表

| 风险 | 影响 | 缓解 |
|------|------|------|
| 时段漂移 | 误判收益 | A' 段 + 包络裁决 |
| ring 过大 | cache 压力 | 上限 1024，超限即停 |

## 观测点

- drop / 重传计数、RSSI、softirq CPU 占比。

## 改动范围（文件级清单）

- `driver/rx.c` ← ring 常量 256→512
- 文档是否需同步：`待勘察（P0）`
