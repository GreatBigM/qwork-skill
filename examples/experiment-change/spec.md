# rx-ring-ab — 规格

> 一句话：验证 RX ring 256→512 是否提升吞吐、降低重传。

## 为什么做

现状/痛点：
- 高负载下 RX drop 与重传上升，吞吐在 64–82 Mbps 之间波动。
- 疑似 ring 偏小导致丢包。

为什么现在做（可选）：下周进入版本窗口，本周必须给出「合入 / 放弃」结论。

## 要什么（成功标准）

| ID | 维度 | 基线 | 目标 | 底线 |
|----|------|------|------|------|
| S1 | TCP RX | 待测（tasks P0） | ≥ 基线 ×1.10 | ≥ 基线 ×1.05 |
| S2 | 重传率 | 待测（tasks P0） | ≤ 1.5% | ≤ 2.0% |
| S3 | 稳定性 | 0 crash / 5 次 | 0 crash / 5 次 | — |

测量口径：`iperf3 -t 60 -P 4`；同 AP、同信道、同位置；A→B→A' 交错，每段 3 次取中位数；裁决阈值 |Δ| ≥5% 为实锤、≤漂移关闭，漂移由 A/A' 包络给出。

## 副作用约束

不碰什么：
- 不改协议栈与 MAC 层。
- 不动中断合并参数。
